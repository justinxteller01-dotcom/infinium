## 1. Current release: `batch1-097165f` (pre-release, 2026-10-28 8:06 PM ET; includes everything below)
- **Elytra thin-plate fix (this commit, pushed, local test jar only, no release; untested in game)**: root cause of the front/back gap + weird connecting textures on Cybernetic / Cyber Psycho / Infinity wings: `renderR3` used vanilla `ElytraModel.createLayer()` (10x20x2 box with `CubeDeformation(1.0)` = a 4px-thick slab). Translucent base + noCull glow drew the front and back faces 4px apart (the gap, visible in flight/edge-on), and the alpha-cut wing shape sits inside the full box rectangle, so the side/top/bottom box-UV strips (u22-23, u34-35, v0-1) rendered as bars of unrelated texels that matched neither face. Fix: `InfiniumWingsRenderer.thinElytraLayer()` = vanilla layout/UVs/poses with `CubeDeformation(1, 1, -0.75)` (~0.5px thick, same width/height); `tools/fix_elytra_strips.py` (idempotent) rebuilt the edge strips of all 763 r3/r7/r5 base/glow/glow_gray/border/echo frames from the exact face texels they touch (MC Cube polygon UV order). Looks, glow sync, CP plates/seams, thrust border, ribbon and Infinity echo (0.02 offset, 1.08 scale clears the thin plate, no z-fight) unchanged. `check_assets.py` asserts both. Offscreen contact sheets (8 views x rest/glide x 3 sets): `/workspace/elytra_check/{before,after}.png`.
- **Sword combat pass (`64dc081`, pushed, local test jar only, no release; untested in game)** (Justin's call, 10-29). Code lives in this repo (`client/anim/*`, `client/SwordSlashClientHandler`, `SwordSlashHandler`, new `SwordCombo`, `client/SwordCooldownHud`); original code, no Punchy code. With Punchy installed Infinium still overrides Punchy for its sword (`SwordAnimTuning.OVERRIDE_PUNCHY`), so the click path (`onStartAttackVanilla`) is the live one.
  - **Stab bug root cause**: the server rate limit required exactly `round((floor(20/speed)-1)*1.25)` server ticks before a stab with zero slack (14 t at base speed, 9 t with Cybernetic speed, i.e. equal to the full-charge time). Client clicks N client ticks apart arrive N-1/N/N+1 server ticks apart (tick phase + packet bunching), so about half of correctly timed stabs were silently dropped server-side while the client had already advanced the combo and played the stab animation. On top of that the client gate (same 1.25x) turned a click at exactly full charge (13 t at base) into a left cut, and the reset window was 1500 ms wall-clock. Fix: no 1.25x gate; shared tick-based `SwordCombo` timings; server accepts with 3-tick slack; a fully charged third click within 40 ticks (2 s, sqrt-shrinks with attack speed, floor 32 t) is always the stab (wins over jump-crit/crouch); early click = plain swing + reset to left/right/stab; charge is read at `startAttack` HEAD (before vanilla resets the ticker).
  - **Combo**: left slash -> right slash -> stab -> twirl (every time). After the stab the combo is locked for stab anim + twirl (`postStabLockTicks`, 34 t at base), enforced client and server.
  - **Animations**: swing length follows the attack-strength delay (94% cuts, 90% stab, twirl 22 t x speed scale), so Cybernetic/Cyber Psycho speed bonuses shorten everything without clipping. Longer windup/strike, bigger arcs (1P 44/62 deg, 3P 85/120 deg), stronger damped follow-through, 3P forearm roll, torso twist that follows the arm (replaces vanilla's 6-tick linear body swing), stab thrusts to centre, stab flows straight into a 360 deg 1P twirl / 3P wrist circle.
  - **Cooldown meter**: 48x5 bold purple bar under the crosshair, energy mode only (tier >= 1 + saber); permanent, glows when full until the next swing; shows the post-stab lockout. Vanilla's attack indicator is not hidden (ours sits below it).
  - **Audio**: twirl and crit-twirl sounds no longer play; charge clips regenerated as subtle swells with no ready ping. New kind `slash2_launch` (5 sounds.json entries, 137 total): slash 1 / slash 2 / stab 3 per set, procedurally generated by `tools/gen_sword_combo_sounds.py` (numpy + ffmpeg vorbis). Server now plays the launch to other players only (the shooter heard it twice before).
